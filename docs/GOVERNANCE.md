# Governance

## Decision-Making
- **Proposals** drive all significant changes (engine, scope, license, policy).
- **Lazy consensus** (7 days, no objection) for uncontroversial proposals.
- **Ranked-choice ballot** for contested proposals (≥3 objectors) or constitutional matters.
- **Voters**: Contributors with ≥1 merged PR to `main`.

## Roles
- **Contributor**: Anyone with a merged PR. Can propose, vote, review.
- **Code Owner**: Listed in `.github/CODEOWNERS`. Required reviewer for their paths.
- **No BDFL, no veto**: The Constitution is the highest authority.

## Meetings
- Optional monthly voice sync (announced in #general). Notes → `docs/MEETINGS/`.
- Async-first: all decisions traceable in Issues/PRs.

## Conflict Resolution
1. Good-faith discussion in the proposal thread.
2. Mediation by two uninvolved code owners.
3. Binding ballot if mediation fails.

## Transparency
- All votes public in the ballot issue.
- All finances (if any) reported quarterly in `docs/FINANCES/`.
