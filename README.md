# Ultimate Dream

A collaborative game project built in the open. We vote on direction, ship playable builds, and share everything.

**Status**: 🟢 Scaffold complete — engine ballot open

## Join in 5 lines
1. Read `CONTRIBUTING.md` and `GOVERNANCE.md`
2. Pick an open proposal or file a new one via **Issues → New → Proposal**
3. Claim a task from the project board
4. Open a PR with `Approved-Proposal: UD-###` in the description
5. Two code-owner reviews + green CI = merged
