# Free-model catalogue

Generated by `tools/free_model_watch.py`. **Do not hand-edit.**

- `latest.json` — the most recent run, used as the baseline for the next diff.
- `<UTC timestamp>.json` — every run kept, so any day can be compared to any other.

Each record is `provider`, `model_id`, `class`, `probe_status`, `http_code`, `detail`, `checked_at`.

`probe_status` means what it says: `ok` = a minimal authenticated completion returned 200 with
choices. `catalogued` = listed by `/models` but not probed this run. `auth`/`gone`/`ratelimit`/
`bad-request`/`unreachable` = the completion was attempted and this is what came back.

A `/models` 200 is not evidence a model works — a gateway can serve the catalogue from a stale
token while every completion returns 401. Only `probe_status: ok` is evidence.

`class` is evidence-based, not name-based: `paid` when the response carries a positive cost,
`free-declared` when the id declares it and the probe did not charge, `free-unpriced` when it
answered 200 with no cost field, `unknown` otherwise.
